# Google Calendar Recreation

A simplified Google Calendar clone built with React, Vite, and Chakra UI.

**Live demo:** https://google-calendar-flame.vercel.app/

## Features

- Week / Weekend / Full Calendar view modes
- Create, edit, and delete events (with optional notes)
- Quick Add templates for common event types
- Focus Mode — filter/dim events by category
- Free Time Finder — highlight open 1-hour slots
- Sidebar summaries: Next Up, Weekly Balance, Busiest Day, Week Mood

## Tech stack

- React + Vite
- Chakra UI
- Lucide icons

## Running locally

```bash
npm install
npm run dev
```
